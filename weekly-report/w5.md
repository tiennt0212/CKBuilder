## Key Learnings
### Lesson 7: Script Basics Highlights
- **Script Structure**: A script consists of `code_hash` (pointing to the binary), `hash_type` (defining how to match the code: Data, Type, Data1, Data2), and `args` (input parameters for the script logic).
- **Validation Lifecycle**: CKB VM executes scripts dynamically based on `cell_deps`. Lock scripts validate *who* can spend the cell, while Type scripts validate *what* state transitions are allowed.

### CCC Wallet Integration
- **Unified Interface**: CCC simplifies multi-wallet support by providing a clean, unified abstraction layer (`Provider` / `Signer`) for handling wallet interactions.
- **State Management**: Wrapped the application context properly to ensure the connected wallet state persists and is globally accessible across the UI components (Wallet Panel, Cell Explorer).
